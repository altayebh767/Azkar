# عداد الأذكار (Android)

تطبيق بسيط بدون أي مكتبات خارجية: زر دائري كبير للعد، اهتزاز عند كل ضغطة واهتزاز أطول عند إكمال الهدف،
قائمة أذكار جاهزة مع هدف لكل ذكر قابل للتعديل، حفظ تلقائي، والعد بأزرار الصوت.

## طريقة بناء ملف APK

### الطريقة 1: Android Studio (على الكمبيوتر)
1. فك الضغط عن المشروع.
2. افتح Android Studio ← Open ← اختر مجلد المشروع، وانتظر انتهاء المزامنة (Sync).
3. من القائمة: Build ← Build Bundle(s) / APK(s) ← Build APK(s).
4. الملف سيكون في: `app/build/outputs/apk/debug/app-debug.apk`

### الطريقة 2: GitHub Actions (بدون تثبيت أي شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد (بما فيها مجلد `.github`).
2. افتح تبويب Actions ← Build APK ← انتظر انتهاء البناء.
3. نزّل الملف `azkar-counter-apk` من قسم Artifacts، وفك الضغط لتجد `app-debug.apk`.

## التثبيت على الهاتف
انقل الملف إلى الهاتف، افتحه، وفعّل "السماح بالتثبيت من هذا المصدر" عند الطلب.
